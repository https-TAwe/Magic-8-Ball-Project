# Magic 8-Ball Project
Inlcudes a code that generates random responses upon a user giving it a question. 

## How the Code Works? 
-The program asks the user for their name and question.
-The question must be a yes, or no question.
-Using a random generator it then provides an answer based on a random number between 1 and 15
-The code makes use of conditional statements to provide a response. 
-Displays the response as the Magic-8-Ball's answer 

## Programming Language Used and how to run: 
Python
-Can be run on Visual Studios after Python has been installed.
